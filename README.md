# kingyo_emu_cpp

金魚（和金）のシミュレータ。**泳ぎを物理で解いています**（アニメーションを描いてはいません）。
計算も描画もすべて C++、Emscripten で WASM にして走らせます。作りは
[suisou_emu_cpp](https://github.com/yomei-o/suisou_emu_cpp) と同じ ABI・同じハーネス。

## 金魚とネオンテトラで変えたところ

**尾びれは体の進行波の続き。** ここが金魚らしさのほとんどです。体の中心線を伝わる波を
`s`（鼻先 0 〜 尾柄 1）で持ち、**尾びれは s > 1 の領域としてそのまま延長**しています。
波は s が大きいほど位相が遅れるので、**尾は体が振り終わってから遅れて返ってきます**。
尾柄に剛体の扇を貼ると、板を振っているようにしか見えません。

| | ネオンテトラ | 和金 |
|---|---|---|
| 体長 | 3cm | 8〜13cm |
| 体高 / 体長 | 0.27 | **0.36**（寸胴） |
| 巡航 | 1.5 体長/秒 | **0.8 体長/秒**（ゆったり漂う） |
| 旋回の角速度 | 3.4 rad/s | **1.7 rad/s**（体が大きくて曲がれない） |
| 曲がるときの湾曲 | 0.16 L | **0.26 L**（大きく弓なりになる） |
| 群れ | 分離・整列・結合 | **群れない**（避けるだけ） |
| 密度 | 0.8 匹/L | **0.05 匹/L**（1匹あたり20L） |
| ひれ | 小さい扇 | 背びれは**基底が長い**、胸びれで漕ぐ、尾は二叉で長い |

**胸びれで漕ぎます。** 金魚は止まるとき・後退するときに胸びれを細かく扇ぎます。
遊泳速度が巡航より遅いほど速く漕ぐようにしてあるので、ホバリングしているのが見えます。

**体色**は素赤（全身朱）と更紗（赤白）を個体ごとに振り分けています。
`src/kingyo_tex.h`（写真から展開したテクスチャ）を置くと、そちらを優先して貼ります。

## モデルを見る

デモの **🔍 モデルを見る** ボタン（または `sim_set(20, 1)`）で、**1匹だけを画面中央に固定**して
泳がせます。体もひれも普通に動くので、形やひれを直すときに魚が画面に入るのを待たずに済みます。

```sh
EMSDK=~/emsdk ./build.sh kingyo_os      # -> wasmdist/kingyo_os/sim.js (+.wasm)
cd wasmdist && python3 -m http.server 8767

clang++ -O3 -std=c++17 -I. -Isrc src/kingyo_os.cpp -o kingyo
./kingyo 128 model.png 0.1 0 0 0.30 3.0 1
#        フレーム数 出力 [密度匹/L] [HUD] [餌フレーム] [画角m] [カメラ距離m] [1でモデル確認]
```
